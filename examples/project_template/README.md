# VSCell project template

Copy this directory to a writable location and run `vscell run` from inside
the copied directory.

- Put source microscopy images in `data/`.
- If candidate masks already exist, put them in
  `segmentation_results/<model>/`.
- Do not create `run/`; VSCell creates it automatically after preflight and
  confirmation.

The folders contain small README placeholders so the empty layout remains
visible when the repository is cloned. Remove those placeholders if desired;
VSCell ignores them because they are not supported image files.
